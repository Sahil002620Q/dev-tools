## 🌟 Core Features

### 🔍 Advanced Filtering & Search
* **Fuzzy Search:** Instant real-time filtering across titles, descriptions, categories, tiers, and popularity.
* **Multi-Select Filters:** Filter down tools dynamically by **Domain** (Development, Data & AI, Cloud & DevOps, APIs, Cybersecurity), **Pricing Tiers** (OSS, Free, Freemium, Paid), and **Popularity** (High, Medium, Low).
* **Reset All Filters:** One-click clear option in settings to reset all criteria.

### 🎨 Premium Aesthetics & Customization
* **Glassmorphism UI:** Built with modern CSS custom variables, radial orb glows, backdrop filters, and subtle hover micro-animations.
* **Flexible Themes:** Smooth theme transition engine supporting Light Mode, Dark Mode (Midnight), Rose, Slate, Forest, Ocean, and Sunset presets.
* **Density Controls:** Instantly swap between **Compact**, **Comfortable (Default)**, and **Spacious** grid templates to customize density.
* **Dynamic Theme Colors:** The browser's window chrome and tab headers dynamically update to match the active theme background.

### 💾 Local Persistence & Custom Libraries
* **Add Custom Tools:** Add your own tools, private documentations, or local web pages directly via a visual form, saved to your local browser storage.
* **Favorites System:** Mark tools with a ❤️ to view them under a dedicated tab.
* **Backup & Restore (JSON):** Complete library export/import. Download your saved favorites and custom tools as a single `devtools-backup.json` file, and restore it on any browser or device.
* **Shell Installer Export:** Export your entire favorites list as a pre-configured `.sh` bash installer script for one-click development environment setup on Windows, macOS, or Linux.

### ⚡ Power-User Features
* **Recently Visited History:** Tracks your last 10 visited tools in a slick history drawer for quick access.
* **Keyboard Hotkeys:**
  * <kbd>/</kbd> or <kbd>Ctrl+K</kbd> — Focus & select the search input
  * <kbd>H</kbd> — Open the recently visited History Modal
  * <kbd>S</kbd> — Toggle the Settings panel
  * <kbd>?</kbd> — Show the Keyboard Shortcuts cheatsheet modal
  * <kbd>Esc</kbd> — Close any modal, drawer, or clear search text

## 🛠️ Technical Stack
* **Frontend:** Vanilla HTML5 (Semantic Structure) & modern ES6 JavaScript.
* **Styling:** Vanilla CSS3 Custom Variables, Flexbox, and CSS Grid.
* **PWA:** Service Worker integration (`sw.js`) with caching for complete offline usability.
* **APIs:** Google S2 Favicon API for automated, high-resolution site icon fetching.
